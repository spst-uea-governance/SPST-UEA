# Roadmap

## Implemented Reference Runtime

- Foundation: typed state, events, adapters, governance, persistence, and tests.
- Phase 2: intelligence amplification and long-term memory integration.
- Phase 3: autonomous goal loop and scheduled maintenance.
- Phase 4: local web cockpit observability API.
- Phase 5: local multi-subject federation and governed self-repair.
- Phase 6: dynamic local tools, rule crystals, and active auto-immunity.
- Phase 7: lifecycle control, priority scheduling, checkpoints, migration, SDK,
  and reproducible benchmark reporting.
- Phase 8: provider-neutral capability maximization that opens latent model
  ability through scaffolding, verification, and paired evaluation.

## Long Horizon

The strategic direction is AI-human coexistence and mutual flourishing through a
next-generation autonomous multi-agent system. This horizon requires:

- collaborative agency between humans and AI systems,
- stronger multi-agent delegation and verification,
- richer local memory and rule-crystal transfer,
- evidence-backed capability amplification,
- cockpit-level human intervention and consent,
- and governance strong enough to keep autonomy auditable.

The current reference-runtime surface has no known executable placeholder areas.
Future work should proceed through RFC evolution, conformance tests, and optional
provider integrations rather than ad hoc expansion.
