# Roadmap

## Implemented Reference Runtime

- Foundation: typed state, events, adapters, governance, persistence, and tests.
- Phase 2: intelligence amplification and long-term memory integration.
- Phase 3: autonomous goal loop and scheduled maintenance.
- Phase 4: local web cockpit observability API.
- Phase 5: local multi-subject federation and governed self-repair.
- Phase 6: dynamic local tools, rule crystals, and active auto-immunity.
- Phase 7: lifecycle control, priority scheduling, checkpoints, migration, SDK,
  and reproducible benchmark reporting.

Future work is limited to RFC evolution and optional provider integrations; the
current reference-runtime surface has no known executable placeholder areas.
