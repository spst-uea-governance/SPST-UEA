# Canonical Glossary

## Action

An externally observable operation initiated by the runtime or one of its authorized modules.

## Architecture

The set of components, boundaries, interfaces, responsibilities, and constraints that define a compliant SPST-UEA system.

## Cognitive Metabolism

The managed cycle by which information is received, evaluated, integrated, retained, transformed, or discarded.

This term is descriptive and MUST be implemented through observable operations.

## Constraint

A rule that limits valid state transitions, actions, or goals.

## Continuity

The measurable degree to which a system reconstructs and preserves relevant state, goals, identity constraints, and operational intent across time.

## Evidence

A test result, benchmark result, formal analysis, experiment, or reproducible observation supporting or rejecting a claim.

## Governance

The mechanisms that monitor, constrain, authorize, reject, repair, or escalate state transitions and actions.

## Goal

A managed representation of a desired future state, including priority, status, provenance, dependencies, and termination conditions.

## Goal Drift

An unapproved or unexplained change in goal meaning, priority, or execution direction.

## Identity

The governed set of persistent invariants, commitments, roles, constraints, provenance, and self-description that define operational continuity.

Identity is not equivalent to personality.

## Identity Drift

A measurable change in identity-relevant state that exceeds expected or authorized variation.

## Inference Engine

A model or service used to generate predictions, reasoning candidates, plans, classifications, or natural-language outputs.

## Memory

Stored information available for future reconstruction or decision-making.

Memory includes episodic, semantic, procedural, policy, and audit memory.

## Model Adapter

A module that exposes a common inference interface over a specific model provider or local model.

## Observation

An input event received from a user, environment, tool, system component, or internal monitor.

## Persistent Agent System

An implementation of the SPST-UEA architecture that maintains managed continuity across multiple state transitions or sessions.

## Reconstruction

The process of deriving a current subject state from prior state, memory, current observations, constraints, goals, and governance rules.

## Reflection

A bounded evaluation process that inspects plans, actions, state, confidence, contradictions, or outcomes and may propose corrective updates.

## Runtime

The execution environment responsible for lifecycle, scheduling, event processing, state transitions, module coordination, observability, and recovery.

## Semantic Stability

The degree to which meaning-relevant representations remain coherent under paraphrase, delay, interruption, state reconstruction, or model substitution.

## State

The complete set of managed values required to describe the system at a specific logical time.

## Subject

A persistent, recursively reconstructed information process represented by managed state and evaluated through observable continuity.

## Subject State

The versioned state object containing identity, goals, memory references, governance status, runtime metadata, and reconstruction information.

## Synthetic Qualia

A proposed descriptive term for integrated internal state-difference signals.

Synthetic qualia are experimental and are not part of the stable engineering core.

## Traceability

The ability to map a claim to requirements, implementation artifacts, tests, benchmark results, and evidence.

## Transition

A governed change from one valid system state to another.
