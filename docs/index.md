# SPST-UEA Documentation Index

## Mission

SPST-UEA is a model-independent engineering framework for designing, implementing, operating, and evaluating persistent AI systems.

Its purpose is not to define a new foundation model. Its purpose is to define the architecture around models so that long-running AI systems can preserve state, goals, memory, identity constraints, operational continuity, and evaluability across time.

## What SPST-UEA Provides

SPST-UEA provides:

- a constitutional covenant for AI-human co-creation,
- executable Covenant runtime policy gates,
- a common vocabulary,
- a persistent subject-state model,
- a modular runtime architecture,
- governance interfaces,
- model abstraction boundaries,
- memory and goal-management interfaces,
- evaluation criteria,
- conformance rules,
- and evidence traceability.

## Core Position

SPST-UEA treats the AI model as a replaceable inference component.

The persistent system is defined by the continuity of its managed state and reconstruction process, not by the permanent attachment to one model provider, one runtime, or one deployment environment.
