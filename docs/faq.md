# Frequently Asked Questions

## Is SPST-UEA a new language model?

No. It is an architecture and evaluation framework around models.

## Does SPST-UEA claim that an AI is conscious?

No. It makes no claim about phenomenal consciousness.

## What does `subject` mean here?

A managed persistent information process represented by versioned state and reconstructed across time.

## Can the model be replaced?

Yes, in principle. Model replacement is a design goal, subject to compatibility and continuity testing.

## Is memory alone enough?

No. Memory is necessary for many implementations but does not by itself provide governance, identity constraints, goal continuity, reconstruction, or evaluation.

## Is LangGraph required?

No. It may be used by a reference implementation, but the standard is framework-independent.

## Is Temporal required?

No. It is one possible durable execution engine.

## Why use RFCs?

RFCs make architectural change reviewable, traceable, and versioned.

## What is the first implementation target?

A minimal persistent agent runtime with:

- subject-state management,
- memory,
- goals,
- reflection,
- governance,
- event scheduling,
- and evaluation hooks.

## What counts as success?

Independent implementation, reproducible evaluation, modular replacement, and evidence-backed improvement over simpler baselines.
